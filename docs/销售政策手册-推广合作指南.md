# 销售政策手册 · 推广合作指南

> **适用对象**：全体销售 / 渠道 / 推广合作人员
> **生效版本**：第一阶段政策 V1.0（2026-10）
> **重要说明**：文中所有奖励金额与比例以平台管理后台实际配置为准，政策调整时会另行通知。本手册数值为当前标准配置。

## 一、一页速览

| 项目 | 内容 |
|---|---|
| 邀请注册奖励 | 每成功邀请 1 位新用户注册，奖励 **$6**（立即计入返利余额） |
| 充值返利 | 被邀请人**每笔充值**，邀请人按比例获得返利，普通推广者 **10%** |
| 客户分层 | 普通推广者 10% → 活跃推广者 15% → 大客户/代理商 20% |
| 返利有效期 | **永久有效**——被邀请人的充值持续产生返利，不设期限 |
| 返利冻结期 | 返利到账后 **7 天**解冻（防退款套利，保护双方） |
| 单个被邀请人返利上限 | **无上限**（资金安全由 IP 风控 + 冻结期保障） |
| 提现方式 | 签约代理商（L3）：可提现；其他推广者（L1/L2）：返利转入账户余额用于消费 |

**一句话卖点**：把平台推荐给朋友或客户，他们每充一笔钱，你就躺赚 10%~20%，上不封顶。

"我们是聚合了 Claude、GPT、Gemini、Kimi、DeepSeek 等国内外主流大模型的 API 一站式平台。客户只需要一个账号、一个接口，就能调用所有主流模型，不用分别注册、充值、维护多个上游。你把平台推荐出去，客户每充一笔钱，你持续拿 10% 起步的返利、永久有效，推荐得越多、比例越高，最高 20%。"

**目标客户画像**：

- 企业客户（用量稳定，适合谈 20% 代理档）

## 三、三级客户分层政策

| 层级 | 达标条件 | 充值返利比例 | 说明 |
|---|---|---|---|
| L1 普通推广者 | 注册即可推广 | **10%** | 全员自动享受 |
| L2 活跃推广者 | 月邀请 ≥5 人 **且** 被邀请人产生真实充值 | **15%** | 联系运营申请，后台批量开通 |
| L3 大客户/代理商 | 团队采购、长期稳定走量 | **20%** | 逐个签约开通，定期复核 |

**销售要点**：
1. 陌生客户一律先按 L1 谈，不要一开口就承诺 15%/20%
2. L2/L3 是你的谈判筹码：客户犹豫时，用"推荐人数达标即可升级"推动他帮你拉新
3. L3 客户由销售负责人审批，不要私自承诺，避免无法兑现

## 四、收益怎么算（给客户演示用）

### 案例 1：轻量推广（L1，10%）
小张邀请了 5 个朋友，每人充值 $10：
- 注册奖励：5 × $6 = **$30**
- 充值返利：5 × $10 × 10% = **$5**
- **合计收益：$35**

### 案例 2：认真推广（L2，15%）
小李是活跃推广者，累计邀请 50 人，人均充值 $20：
- 注册奖励：50 × $6 = **$300**
- 充值返利：50 × $20 × 15% = **$150**
- **合计收益：$450**

### 案例 3：团队/代理（L3，20%）
某技术社区管理员签约代理档，社区内 200 人月均充值 $10：
- 注册奖励：200 × $6 = **$1,200**
- 月度充值返利：200 × $10 × 20% = **$400/月**（永久持续）
- **首年预计收益：1,200 + 400 × 12 = $6,000**（次年起每年持续 $4,800+）

> 演示话术："返利不是一次性奖励，是跟着客户消费走的**持续性收入**——你的客户用得越久，你赚得越久。"

## 五、到账规则（务必向客户讲清楚，避免售后纠纷）

1. **注册奖励**：被邀请人注册成功即到账，进入邀请人的返利余额
2. **充值返利**：被邀请人每笔充值到账后，返利实时计提
3. **7 天冻结期**：新返利有 7 天冻结，期满自动解冻可提现。解释口径："这是防止刷单和退款纠纷的保护机制，对正常用户没有影响"
4. **永久有效期**：被邀请人的充值持续产生返利，不设期限。解释口径："你的客户用多久，你就收益多久，这是一份持续性收入"
5. **无单人上限**：单个被邀请人的充值返利不封顶，大客户消费多久、返利就跟多久。解释口径："上不封顶是平台的政策承诺，资金安全通过同 IP 风控和 7 天冻结期保障"
6. **提现（分级）**：与平台**签订代理协议**的 L3 大客户/代理商，返利可提现；L1/L2 推广者的返利余额可一键转入账户余额，用于 API 消费

## 六、常见问题 FAQ（客户最常问）

**Q1：被邀请人有什么好处？**
A：被邀请人填你的邀请码注册，即刻加入平台正常使用全部功能，不影响他的任何权益。你的收益来自平台的推广预算，不从他账上扣。

**Q2：我邀请的人不充值，我有钱拿吗？**
A：有注册奖励（$6/人），但大头是充值返利。所以优先推荐**真实有用量需求**的客户。

**Q3：返利什么时候能提现？**
A：实时计提、7 天解冻。解冻后，签约代理商可申请提现；其他推广者的返利转入账户余额直接用于 API 消费。想获得提现资格，可联系运营洽谈代理协议。

**Q4：我自己邀请自己可以吗？**
A：**不可以**。平台有同 IP 多账号风控，同一网络环境下同一邀请人名下注册多个账号会被拦截或进入人工审核，违规收益会被清零。

**Q5：比例会一直不变吗？**
A：L1 全局比例调整时会提前公告；L2/L3 比例按签约协议执行。

**Q6：怎么升级到 15% / 20%？**
A：联系运营提交申请，提供邀请人数和被邀请人充值情况，审核通过后后台直接开通。

## 七、销售红线（违规后果：清零收益 + 封禁账号）

1. ❌ **自邀自刷**：用自己或亲友的多账号注册套取注册奖励（同 IP 风控自动拦截）
2. ❌ **虚假承诺**：向客户承诺政策外的收益或比例（如私自承诺提现资格、超政策比例）
3. ❌ **诱导充值**：以返利为目的诱导客户超需求充值
4. ❌ **私建返利 layered 分销**：不得私自向下游二次分销、层层抽成，平台当前不支持多级分销
5. ❌ **渠道套利**：利用管理员充值、对公转账等特殊通道制造虚假流水套取返利（该通道默认不产生返利）
