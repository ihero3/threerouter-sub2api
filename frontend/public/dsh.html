Why

为什么是 dsh-image-video

轻量、即装即用的文生图 / 文生视频入口。两个工具、登录即用、零外部依赖。

自然语言触发

模型在对话中自主决策何时调用工具，无需手动指令。一句「帮我画…」即可创作。

登录 Threerouter 即用

无需配置任何 Provider，登录 Threerouter 账号即可使用全部模型，渠道由平台统一调度。

异步不阻塞对话

TaskManager 托管轮询生命周期，插件卸载自动取消排队任务、清理定时器，杜绝内存泄漏。

本地落地 + 内嵌渲染

图片字节持久化到 attachment，模型只见文本摘要，纯文本模型照常工作；UI 可内嵌渲染。

FAQ

常见问题

API Key 安全吗？会上传我的数据吗
API Key 仅在本地使用，不上传任何远程服务。生成通过你的 Threerouter 账号由平台统一调度完成。
生成质量由谁决定？
模型输出质量由平台提供的模型决定。插件负责正确传参、可靠轮询和统一异常分类，不改变模型本身的能力。
需要先安装 Deepseek Harness for Threerouter 吗？
dsh-image-video 是 Deepseek Harness for Threerouter 的插件，运行在 DSH 运行时中。使用桌面端可从 GUI 直接安装，也可通过 CLI 插件命令添加到任意 profile。
